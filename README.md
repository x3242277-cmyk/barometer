# ברומטר · מדד הסקרים והאמינות

אתר סטטי (HTML/CSS/JS בלבד, ללא build ותלויות) שמדרג מכוני סקרים לפי הדיוק שלהם,
מציג את סקרי 2026, בונה תחזית מנדטים משוקללת, ומציג פילוח של תוצאות האמת לפי
אזורים ומגזרים וכן מודל דמוגרפי באחוזי תמיכה שאינו נשען על סקרים כלל.

## עמוד הבית — קיר המנדטים

עמוד הבית מציג רק את מה שרוב הגולשים באים לראות: דיוקן לכל ראש רשימה, מספר
המנדטים בצבע הגוש, ומעליהם משפט אחד שמסכם את התמונה. ההסברים, הנוסחאות
והגרפים עברו כולם לעמוד "שיטת החישוב". מתג בראש העמוד מחליף בין "תחזית
הברומטר" (עם הנחות המודל) ל"משוקלל אמינות" (ממוצע הסקרים בלבד).

**הכותרת נבנית מהמספרים בכל עדכון** (הפונקציה `homeHeadline` ב-`app.js`) —
אין ניסוח ידני. חיווי ▲/▼ ליד כל מספר משווה לצילום התחזית הקודם ב-
`data/forecast-history.json`.

**הדיוקנאות** נגזרים פעם אחת מקובצי המקור ברזולוציה מלאה שבתיקיית `תמונות/`
(שאינה נכנסת ל-Git) באמצעות `scripts/crop-leaders.py`. הפלט המעובד נשמר תחת
`assets/leaders/<id>-full.jpg`.

## הרצה מקומית

האתר חייב להיות מוגש משרת (בגלל `fetch` של קבצי ה-JSON) — פתיחת `index.html`
ישירות מהדיסק לא תעבוד.

```bash
python3 -m http.server 8000
# ואז http://localhost:8000
```

## עדכון הסקרים

```bash
node scripts/update-polls.mjs          # שליפה מהמקור (עשרת הסקרים האחרונים)
node scripts/update-polls.mjs --full   # סריקת כל סקרי השנה מסייטמאפ המקור
node scripts/update-polls.mjs --dry    # בדיקה בלי לכתוב
node scripts/update-polls.mjs --file raw.json
```

**כלל התצוגה**: סקרים מ-`from` (01.08.2026) ואילך, ולכל היותר `maxPerOutlet` (4)
הסקרים האחרונים לכל כלי תקשורת. סקר חדש של ערוץ דוחק את החמישי שלו מהתצוגה
בלי למחוק אותו — הארכיון שומר הכול. הכלל מוגדר פעמיים בכוונה, ב-
`selectDisplayPolls` שבסקריפט ובזו שב-`assets/app.js`, כדי שגם טעינת דף בלי
הרצת הסקריפט תסנן נכון.

`--full` לא מוריד את כל 185 הסקרים: הוא גוזר מהסלאגים שבסייטמאפ את ארבע
הכתובות האחרונות לכל ערוץ ומוריד רק אותן.

**לפני ההרצה הראשונה** ערכו את `scripts/config.json` והכניסו את `sourceUrl` של
מקור הסקרים שלכם. אם המקור מחזיר מבנה JSON שונה — יש להתאים את הפונקציות
`pickArray()` ו-`normalize()` בראש `scripts/update-polls.mjs`; שתיהן קצרות
ומתועדות.

הסקריפט:

* שומר כל סקר שנשלף אי־פעם ב-`data/polls-archive.json` (שום דבר לא נמחק),
* מייצר את `data/current-polls.json` לפי כלל התצוגה שלמעלה,
* מזהיר על סקרים שסכום המנדטים בהם אינו 120 או שאין להם `sourceId`.

בנוסף, גם הדפדפן מחיל את הכלל מחדש בכל טעינה — כך שסקר חמישי של ערוץ נושר
מהתצוגה גם אם הסקריפט לא רץ.

## ליל הבחירות ותוצאות אמת

הכרטיסיות "ליל הבחירות" ו"תוצאות אמת" קוראות את `data/live-results.json`.
הקובץ יכול להתעדכן מכל מקור עתידי — סקריפט מקומי, API, מערכת אנליטיקה או מקור
חיצוני — והדף ירענן אותו אוטומטית פעם בדקה כשהוא פתוח.

המבנה הנתמך:

* `sample.parties` — מדגם המנדטים הראשון, לפי מפלגות.
* `actual.parties` — תוצאות אמת לפי מפלגות, כולל `votes`, `pct` ו־`mandates`.
* `actual.countedPct`, `actual.validVotes`, `actual.invalidVotes` — מצב הספירה.
* `traffic.activeViewers`, `traffic.todayViews` — נתוני צפייה באתר, לאחר חיבור
  שירות אנליטיקה.

בתוך הכרטיס יש שתי עמודות: מימין מפלגות גוש הימין, משמאל המרכז–שמאל
והרשימות הערביות, כל עמודה מסודרת מהמנדטים הרבים למעטים. מספרי הגושים עצמם
אינם מודפסים — הם מופיעים בריחוף על פס הגושים.

עמוד הסקרים מציג **כרטיס אחד לכל כלי תקשורת** — הסקר האחרון שלו — ובורר
התאריך שבכותרת הכרטיס מחליף לסקר קודם של אותו כלי תקשורת בלי להזיז את הכרטיס
ממקומו. אין תצוגת טבלה; המתג בשורת הסינונים מחליף בין הכרטיסים לבין השוואת
המכונים.

בכרטיס הסקר מופיע מעל התוצאות פס הגושים בלי מספרים, עם שני קווי רוב — אחד
מכל קצה — כדי שכל גוש גדול ייקרא מול 61 מהצד שלו, ועם וי מעל גוש שהגיע ל־61.

שיוך הגושים בתצוגה מחולק לשלושה: ימין, מרכז–שמאל וערבים. ש״ס ויהדות התורה
נספרות בגוש הימין, ורע״ם נספרת בגוש המרכז–שמאל. הפילוח הפנימי של המגזר החרדי
נשאר רק בעמוד המודל הדמוגרפי, שם הוא נתון המחקר עצמו ולא שיוך פוליטי.

## מדד אמינות המכונים

הכרטיסייה "מדד אמינות המכונים" בודקת אילו מכונים היו קרובים לתוצאות האמת ואילו
פספסו. המדד מכויל על שתי מערכות בחירות — הכנסת ה־24 והכנסת ה־25 — כל אחת
בחלון של 30 הימים שלפני יום הבחירות.

**איך מחוברים שני הכיולים**: כל מערכת מקבלת ציון נפרד באותה נוסחה, והציון
הסופי הוא הממוצע שלהם ב**משקל שווה** — לא משוקלל לפי כמות הסקרים. זה נגזר
מאותו כלל שלפיו אין באתר רכיב שמתגמל כמות פרסומים. מכון שהופיע רק במערכת אחת
מקבל את הציון שלה ומסומן ככזה בכרטיס שלו.

**חלוקת הגושים אינה קבועה בקוד**: כל קובץ כיול מגדיר אותה בעצמו תחת `blocs`,
ולכן אפשר להוסיף כנסת נוספת בלי לגעת בנוסחה. בכנסת ה־24 ימינה נספרת בגוש
היריב — שם הרכיבה בפועל את הממשלה שקמה — והרשימה המשותפת ורע״ם נספרות מחוץ
לשני הגושים, כפי שעמדו בזמן הסקרים.

**סקר בלי שם מכון אינו נכנס לציון**: בכנסת ה־24 שישה מתוך 34 הסקרים פורסמו
במקור בלי ייחוס לסוקר. הם נשמרים בארכיון ומוצגים בטבלה מסומנים, אך אינם
נזקפים לאף מכון. עדיף חסר על פני ניחוש.

אפשר להגדיר למכון נוכחי שיוך כיול היסטורי דרך `calibrationFirm` בקובץ
`data/pollsters.json`. כך נקסט דאטה (שלמה פילבר, ערוץ 14) יורשת את כיול
דירקט פולס. סקרי צוריאל שרון ב-i24NEWS נרשמים ישירות תחת דירקט פולס — זה
אותו מכון, לא שני סוקרים.

### אוטומציה

`.github/workflows/update-polls.yml` מריץ את הסקריפט כל יום ב-09:00 וב-21:00
שעון ישראל, ועושה קומיט אם משהו השתנה — כולל בנייה מחדש של `dist/`.
ל-cron של GitHub אין אזור זמן והוא לא יודע על מעבר שעון, ולכן מוגדרות ארבע
הרצות (06/07/18/19 UTC) והשלב הראשון בג'וב מפיל את זו שלא נופלת על 09:00 או
21:00 בשעון ישראל. לחלופין, ב-cron רגיל על שרת:

```
0 5 * * *  cd /path/to/barometer && /usr/bin/node scripts/update-polls.mjs >> logs/polls.log 2>&1
```

## השלמת נתוני האמת לכל 1,200 היישובים

עמוד "פילוח אזורי" מציג כברירת מחדל רק יישובים שנתוניהם אומתו מול מקור מפורסם.
כדי למלא את הכול מהקובץ הרשמי:

1. הורידו את קובץ התוצאות לפי יישובים — מ-[data.gov.il](https://data.gov.il/dataset/votes-knesset)
   או מ-[votes25.bechirot.gov.il](https://votes25.bechirot.gov.il/cityresults).
2. הריצו:

```bash
node scripts/import-official-results.mjs --file expb.csv
```

הסקריפט מזהה את קידוד windows-1255, ממפה את אותיות הרשימות של 2022, ממלא את
הנקודות שכבר יש להן קואורדינטות על המפה, ומוסיף טבלה מלאה וניתנת לחיפוש של כל
היישובים — שנחשפת בעמוד אוטומטית ברגע שהיא קיימת.

## מה חשוב לדעת על המספרים

* **ציון האמינות** מורכב מ־60% דיוק בגושים, 30% דיוק במפלגות ו־10% עקביות
  (65% יציבות הגוש לאורך החודש, 35% יציבות המפלגות), ומחושב על שתי מערכות בחירות במשקל שווה. אין רכיב שמתגמל כמות
  פרסומים.
* **כלל אחיד למפלגות**: התחזית אינה מפעילה רצפות מנדטים או תיקונים ייעודיים. התרחיש הדמוגרפי החרדי מוצג בנפרד ואינו משנה את הממוצע.
* **שיוך גושים ידני**: "עמך ישראל" ו"נועם" משויכות לגוש הימין, ורע״ם
  ו"בית ציוני" לגוש המרכז–שמאל, מעל לשיוך שמופיע בנתוני הסקר הגולמיים. השיוך מוגדר ב-
  `ALIGN_OVERRIDE` בראש `app.js` כדי שרענון נתונים לא ידרוס אותו.
* **צבע לכל מכון**: `color` בכל רשומה ב-`data/pollsters.json`. הגוונים עמומים
  ואינם נושאים משמעות פוליטית — הם רק מאפשרים לעקוב אחרי שורות של אותו מכון
  לאורך הטבלה, ולכן הם מובחנים מצבעי הגושים.
* **האנקדוטות** בעמוד הבית נבנות מהנתונים עצמם בכל טעינה, ומתחלפות אחת
  לשלושה ימים לפי התאריך. אין רשימה כתובה מראש — כל מספר בהן מחושב.
* **המודל הדמוגרפי** רץ כברירת מחדל לפי איחודי הרשימות של 2026 (הדמוקרטים,
  הרשימה המשותפת, הציונות הדתית עם הבית היהודי), כך שקולות שירדו לטמיון
  ב־2022 נספרים בו. מתג בעמוד מחזיר אותו למבנה 2022 — ושם הוא משחזר את
  התוצאה מנדט במנדט בגידול אפס, כולל בדר־עופר והסכמי העודפים. זהו מבחן
  השפיות שלו.
* **מכון ללא כיול** מ-2022 אינו נפסל; הוא מקבל משקל ניטרלי של 70 ומסומן ככזה.

### עמוד הבית: מסע החישוב
`assets/intro.js` ו־`assets/intro.css` מוסיפים את "הצגת החישוב" — במה במסך מלא שנפתחת עם כפתור "טענו את הנתונים". שלב 1, טעינת הנתונים ממאגרי המידע, עובר מאגר אחר מאגר (תוצאות האמת 2022, ארכיון הכיול, דמוגרפיה, ערוצים, מכונים, ארכיון הסקרים): כל מאגר מתחבר, נטען (מונה, אייקון מאגר שמתמלא), ושולח את הרשומות למנוע כמילים שנוסעות לאורך הקישור; הסקרים נשלחים אחד־אחד, וכל רשומה מודגשת בלוח "נטען עכשיו" וביומן. שלב 2, הניתוח: כיול כל מכון מול 2022 (עמודות אמינות), ואז ממוצע פשוט → משוקלל → אחוז חסימה → 120 מושבים על גרף המדידות. בסוף מסדר המפלגות — הפורטרטים, עמודות שעולות מעליהם והמספרים שעולים — עם כותרת "מי עלה ומי ירד מאתמול" והערה קופצת עם הפירוט (מתוך forecast-history.json), והכרטיסים טסים למקומם בקיר. כל המספרים נגזרים מפונקציות החישוב הקיימות; התוצאה היא הקיר הרגיל של renderHome. אפשר לדלג (Esc או "דלג לתוצאה") ולהריץ מחדש; יציאה מהבית מבטלת; לשונית ברקע משהה; העדפת תנועה מופחתת והדפסה מדלגות. שני הקבצים נכללים גם בגרסה העצמאית.
